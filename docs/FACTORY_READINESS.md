По уточнению16.11 Telegram и VK подключаются позже через приложение. На экране Аккаунты есть заметные кнопки настройки, встроенные инструкции и необязательная проверка Telegram без отправки; локальные анализ и монтаж не требуют этих доступов. Живые чек-пойнты Telegram/VK отложены, не закрыты. Остальные API/Helix/рекламные и живая сквозная приёмка остаются по исходному ТЗ. Для TikTok Display API предусмотрен ручной путь при отсутствии допуска. Разрешений на настоящие публикации или релиз нет. Локальный путь настройки проверен без подключения настоящих аккаунтов.

Карта содержит 38 групп требований Linux. Пользовательское подключение VK и привязка существующих видео проверены в изолированном окружении. Живые чек-пойнты требуют доступа или материала рекламодателя; повтор завершённых тестов этого не заменяет. Цель остаётся незавершённой.
