# Фабрика контента: работа и восстановление

Это инструкция для текущей рабочей ветки. Номер версии пока 0.3.0; выпуск 1.0 не создан. Полный статус и результаты проверок находятся в `FACTORY_PROGRESS.md`. Доступы площадок и живые публикации проходят отдельную проверку.

## Первый канал

1. Добавь фон и баннер в библиотеку Студии. Настрой именованный шаблон в **Шаблонах**.
2. В **Каналах** создай профиль: источник, шаблон, параметры анализа, язык, число роликов на запись, режим работы и цели публикаций.
3. Укажи права и кредит. При неуказанных правах используется режим с одобрением. Кредит автоматически включается в подпись.
4. Для удалённого источника отдельно включи мониторинг, интервал и фильтры. Повторный опрос пропускает уже найденные записи. Папка наблюдения принимает стабильные видеофайлы.
5. Добавь запись или нажми проверку источника. На **Фабрике** видны стадии, ошибки и журнал. Пауза сохраняется на диск и применяется на границах операций.

Монитор работает, пока приложение открыто. Закрытие окна не заменяет фонового сервера: для ночного задания оставь приложение запущенным. Каналы без доступного источника показывают ошибку и время следующей проверки.

## Режимы и проверка роликов

| Режим | Путь |
| --- | --- |
| Авто | Отбор по порогу и top-N → черновик → QC → финал → подписи и свободные слоты целей |
| С одобрением | Доходит до Inbox; пакетное одобрение запускает финалы и планирование |
| Вручную | Открывается прежняя Студия: импорт → анализ → моменты → черновики → финал |

QC проверяет основное видео, звук, формат, длительность, наличие слов для субтитров и лицо в реакционной раскладке. Замечания направляют ролик в Inbox с причиной. Клавиши Inbox: **→** одобрить, **←** отклонить, **A** выбрать все. Порог и потолок роликов на источник задаются в профиле.

Для длинных VOD скаут изучает дешёвые сигналы всей записи, затем Whisper обрабатывает горячие окна. «По N секунд» режет запись подряд; язык «авто» включает определение языка. Чат и клипы Twitch подключаются отдельно. TwitchDownloaderCLI и Client ID/Secret Helix нужны только для соответствующих сигналов. Установка утилиты и загрузка моделей выполняются явным действием пользователя.

## Реакция и камера

1. Выбери импортированную запись в редакторе камеры канала.
2. Поиск лица требует необязательную YuNet. Её кнопка загрузки отделена от основных моделей.
3. Выбери область вебкамеры; при необходимости проверь запись целиком, затем прими предложенную рамку и сохрани канал. Предложение не записывается автоматически.
4. В шаблоне выбери «Реакция»: круг с геймплеем, полный кадр либо раскладка с рамкой. Позиция, размер, обводка, тень и поведение во время баннера настраиваются. По умолчанию круг замирает вместе с основным видео.
5. Кнопка предпросмотра создаёт кадр тем же ffmpeg-графом, что финал. Перед рендером выбранного фрагмента проверяется наличие лица. Потеря лица отправляет ролик в Inbox.

## Аккаунты, подписи и календарь

Telegram и VK можно подключить позже: анализ и монтаж работают без них. В начале экрана **Аккаунты** нажми **Настроить Telegram** или **Настроить VK** — откроется нужная форма. Рядом с каждой формой есть раскрываемая инструкция.

Для Telegram создай бота через @BotFather, добавь его администратором канала с правом публикации, затем укажи токен и @имя либо числовой ID канала. Чтобы подготовить настройки на будущее, сними флажок «Канал включён для публикаций» перед сохранением. Кнопка **Проверить доступ Telegram** показывает бота, канал и право публикации; она не отправляет сообщений, не сохраняет и не включает аккаунт. Для сохранённого профиля можно оставить поле токена пустым: проверка использует связку ключей. После изменения полей или выбора другого профиля результат убирается; после перезапуска проверь доступ заново при необходимости. Сохранение само по себе не проверяет права бота. После подключения выбери канал в целях профиля и назначь ролики в календаре.

Кнопка настройки VK открывает **статистику** уже опубликованных роликов. Проверка читает счётчики; автозагрузка клипов в VK пока недоступна. Дальнейшая привязка финала описана в разделе ниже.

Подключи аккаунты в **Аккаунтах**, задай каждой паре аккаунт/площадка окно, паузу и суточный лимит. Настройки площадок:

- **Telegram:** Bot API token и канал, в котором бот имеет право публиковать видео.
- **YouTube:** Desktop OAuth Client ID/Secret, loopback, вход в нужный канал. Видимость задаётся явно. Реальные квоты определяются проектом Google.
- **Instagram:** Business/Creator, токен и права Meta; фактический лимит читается перед публикацией. Нужен допуск приложения и аккаунта.
- **TikTok:** прежний профиль Chromium/Edge либо API в Студии; общий календарь использует отдельные браузерные профили. Вёрстка Studio и допустимая длина требуют живой проверки.
- **VK:** в разделе «VK · статистика» подключается пользовательский токен для чтения video.get. Проверочная ссылка определяет владельца видео: положительный ID для пользователя, отрицательный для сообщества. Доступ к статистике не подтверждает право загрузки. Автопубликация VK пока ожидает доступного тестового аккаунта и подтверждения API/селекторов.

В редакторе подписи выбираются площадка, аккаунт и ролик. Текст необязателен: вставь свой и нажми «Проверить и сохранить подпись» либо «Применить текст ко всем». Общий текст заменяет только тело описания готовых роликов этого экрана; хэштеги и реквизиты каждого сохраняются. При выборе общей подписи площадки также обновляется текст сохранённых вариантов аккаунтов. Для отдельного аккаунта меняется только его вариант. Пустой общий текст убирает текст у всех выбранных роликов.

«Сгенерировать хэштеги» подбирает локальной моделью три ключевые темы и сохраняет их, сохраняя введённый текст. Хэштеги можно отредактировать вручную. Фабрика назначает слоты и без текста, и без модели для подписей. Кредит, ссылка, UTM и промокод добавляются из профиля/кампании. Минимальной длины нет; TikTok допускает до 3999 единиц UTF-16. Заголовок YouTube обязателен независимо от необязательного описания. Ранее сохранённые подписи доступны для редактирования.

В старой панели TikTok «Свой текст на все» тоже сохраняет собственные хэштеги роликов. Чтобы заменить их общим набором, включи «Заменить хэштеги общими». Если текст вместе с тегами хотя бы одного ролика не помещается в лимит, вся пачка остаётся без изменений.

Уже назначенный слот хранит снимок подписи. После сохранения нового текста или хэштегов в Студии выбери публикацию в Календаре и нажми «Обновить подпись из редактора». Обновится вариант её аккаунта и заголовок YouTube; время, видимость и настройки видео сохранятся. Отправляющиеся, опубликованные и требующие проверки задачи редактировать нельзя. Для задачи с ошибкой обновление подписи сохраняет ошибку и не запускает повтор.

До начала отправки можно обновить подпись, перенести или отменить слот и во время подготовки видео. Фабрика повторно проверяет сохранённые данные перед отправкой: перенос откладывает публикацию, отмена останавливает её, обновление текста требует повторного чтения новой подписи.

Если подготовка задержалась, ближайший ролик сохраняет свою очередь. Пауза между отправками считается от фактического времени предыдущей публикации; следующие слоты при необходимости сдвигаются. Будущие брони учитываются при назначении и переносе, поэтому календарь не занимает одно время дважды.

Календарь показывает день/неделю. Ролик можно поставить в ближайший свободный слот, перенести точным временем или перетаскиванием. Метаданные и выходной профиль фиксируются при назначении слота. Автозаполнение использует цели сохранённого профиля и не создаёт дубль ролик×аккаунт. Публикации запускаются отдельной кнопкой.

Если назначенный ролик монтируется заново, календарь показывает **«Ожидает финал»** и причину. Слот и подпись сохраняются, остальные готовые ролики продолжают выходить. После проверки обновлённого черновика одобри его и собери финал в Студии: запущенная очередь сама подхватит готовый файл. Отклонённый черновик остаётся в ожидании до повторной проверки либо отмены публикации. Ожидание ручного одобрения само по себе не блокирует сон ПК; идущий монтаж и готовые будущие слоты блокируют его при включённой защите от сна.

Длительность и битрейт выходного файла задаются в Настройках для каждой площадки. Существующий финал сохраняется, для отправки готовится отдельный вариант H.264/AAC. У импортированного готового файла нет исходных слоёв; запечённую «Часть N» удалить автоматически нельзя.

## Неопределённая отправка и авария

После потери ответа площадки отправка может уже состояться. Статус **«Требует проверки»** (`needs_check`) блокирует повтор. Сначала открой площадку и проверь результат. Затем явно отметь отправку состоявшейся, разреши повтор или убери задачу. Неопределённые отправки автоматически не повторяются.

Настройка **«Продолжать при запуске»** восстанавливает обработку и ранее запущенный publisher. Сохранённые паузы, ошибки, капча и `needs_check` требуют действия человека. Ручная пауза переживает перезапуск. Капча проходится человеком в браузере.

События жалоб и ограничений вводятся в профиле канала. Достижение порога сохраняет паузу канала; разбор события сам по себе её не снимает. Другие каналы продолжают работу.

## Кампании и аналитика

Кампания задаёт рекламодателя, несколько баннеров, даты, вес, общий/суточный лимит, каналы, площадки и ссылку/промокод/UTM. Выбор закрепляется при создании черновика. Предпросмотр следующих назначений не меняет историю. Баннеры поддерживают хромакей и альфу PNG/WebM; библиотека проверяет фон/углы и длительность.

Отчёт кампании содержит ролики, публикации и последние доступные метрики, сохраняется в самодостаточный HTML и CSV. В отдельном окне отчёта доступна печать/PDF.

Аналитика собирает доступные YouTube statistics, Instagram insights и VK video.get. Профиль статистики VK подключается в «Аккаунтах», уже опубликованный ролик связывается с локальным финалом в «Аналитике» (порядок ниже). Для TikTok нужен отдельный допуск Display API; Telegram не даёт боту универсального чтения просмотров. Недоступные метрики остаются пустыми; можно ввести ручной замер с его происхождением. Настоящий ноль показывается как ноль.

Подсказки изменения весов появляются после 50 разных роликов с замерами около 48 часов, нормированными на медиану аккаунта. Вес изменяется только кнопкой пользователя; снимки старых задач остаются прежними.

## Сон, диск и диагностика

Локальная модель и GPU-рендер разделяют видеопамять. Перед загрузкой LLM приложение дожидается уже идущих GPU-рендеров; новые черновики и выходные варианты в это время кодируются на CPU. Whisper при занятой карте тоже выбирает CPU. Если установлен `nvidia-smi`, свободная память проверяется перед LLM/NVENC. После отказа NVDEC повтор идёт с декодированием на CPU, после отказа NVENC — с кодированием X264. Исходный финал сохраняется, временный недописанный файл удаляется. Для такой работы ничего дополнительно скачивать не нужно.

**Защита от сна** включается при работе, мониторинге и ожидании назначенного слота; при простое снимается. На Linux используется уже установленный `systemd-inhibit`, на Windows — `SetThreadExecutionState` (живая Windows-проверка ещё требуется). Выключенный компьютер и закрытое приложение не выполняют расписание.

**Трей и запуск при входе** включаются только переключателями в Настройках. Перед «Скрыть окно в трей» проверь, что значок появился в панели; его меню возвращает окно и завершает приложение. Крестик завершает приложение. Скрытое окно продолжает работу, выключение трея возвращает его. На Linux требуется AppIndicator и панель с поддержкой трея; недоступная библиотека показывается ошибкой. Если панель не подтверждает поддержку значков через StatusNotifier, скрытие отклоняется и окно остаётся открытым. Автозапуск создаёт собственный файл в пользовательском XDG autostart (Linux) или Startup (Windows), не меняя установленную программу. При входе открывается обычное окно; после перемещения программы выключи/включи автозапуск заново.

**Диск** показывает категории и зарегистрированные загрузки по каналам. По умолчанию: 14 дней, 100 ГБ, автоочистка выключена. Сначала удали просроченные загрузки или измени срок/лимит. Для ручной очистки требуется подтверждение; при включённом авто политика применяется раз в 5 минут. Лимит 0 означает отсутствие ограничения объёма. Сохранённая пауза не разрешает удалять исходники незавершённой задачи.

Очистка защищает Inbox, незавершённый монтаж/публикации, библиотеку и готовые файлы. Во время анализа, рендера и чтения камеры удаление ждёт освобождения исходников. Импортированные файлы вне папки загрузок и символические ссылки не удаляются. История источника сохраняется после очистки; для повторного монтажа исходник придётся скачать заново. Невыполнимый лимит объясняется защищёнными файлами.

**Диагностика и журналы** находятся в Настройках. «Проверить состояние» показывает очереди и структурированные события. «Сохранить диагностику» создаёт JSON-пакет с версией, схемой/целостностью связей БД, счётчиками, ресурсами и событиями. Свободный текст заменён категорией и SHA-256. В пакет не включаются ключи, подписи, URL и имена файлов/каналов/аккаунтов. Подробные сообщения остаются на Фабрике в «Что происходит». Структурированный журнал `logs/runtime*.ndjson` ограничен двумя файлами по 512 КБ.

## Файлы и совместимость

Данные: Linux `~/.local/share/app.avtonarezka.desktop`, Windows `%LOCALAPPDATA%\app.avtonarezka.desktop`. Основная БД `avtonarezka.db` мигрирует атомарно; прежние проекты, ассеты, очередь и история TikTok переносятся. Перед переносом данных на другой ПК закрой приложение и сохрани всю папку данных вместе с внешними исходниками/финалами. Секреты из системной связки ключей отдельно не копируются пакетом диагностики.

Загрузки фабрики — `sources/`, превью — `drafts/`, варианты площадок — `output-variants/`. Импорт/скачивание одиночного YouTube в прежней Студии сохраняют старый путь. Финалы по умолчанию — `Видео/Автонарезка`, папка меняется в Финале.

## Статистика уже опубликованного ролика VK

1. В **Аккаунтах → VK · статистика** введи название, прямую публичную ссылку вида `https://vk.com/clip-123_456` или ID `-123_456` и пользовательский токен своего приложения VK с доступом к видео. Нажми «Проверить и сохранить VK». Проверяется только чтение счётчиков. Токен хранится в связке ключей; если доступна только память, интерфейс сообщит, что после закрытия потребуется повторный ввод.
2. В **Аналитике** раскрой «Связать уже опубликованный ролик VK». Выбери профиль владельца, соответствующий локальный финал или импортированное готовое видео, ссылку/ID и фактическую дату публикации. Нажми «Проверить и связать ролик».
3. Проверенный первый замер появится в общей аналитике и отчёте закреплённой кампании. Неизвестный счётчик остаётся пустым, настоящий ноль показывается нулём. Автоматический сбор следует общему переключателю аналитики и переключателю профиля VK. Кнопки «Пауза сбора»/«Включить сбор» в списке профилей меняют локальную настройку без запроса к VK, в том числе при истёкшем токене.

Повторная привязка той же пары финал/профиль с теми же ID и датой возвращает прежнюю запись. Изменить существующую историю, заменить неопределённую отправку или привязать одно VK-видео к двум финалам этим действием нельзя. Для другого владельца создай новый профиль. Обновление токена повторно проверяет доступ и снимает ожидание после прежней ошибки авторизации. При отказе записи в связку ключей профиль остаётся на паузе; выбери его в списке и повтори сохранение.

Эта форма регистрирует видео, которое уже размещено вручную: она не загружает файл в VK. Ссылки с ключами доступа, дополнительные параметры и скрытые видео не поддерживаются этим путём.
